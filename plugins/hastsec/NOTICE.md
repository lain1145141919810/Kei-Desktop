# External HAST-SEC runtime

This package contains the Kei adapter. It uses HAST-SEC v0.1.1 from revision `f4d5c9aa32f9d04e249585e0b2e6d4c56572ca51` as a separately installed backend. The upstream solver and motion data are provided for noncommercial learning and research under HAST-SEC's license. Third-party data and tools have their own terms. Retain the upstream notices when working with that checkout.

- [Pinned HAST-SEC source and license](https://github.com/lain1145141919810/HAST-SEC/tree/f4d5c9aa32f9d04e249585e0b2e6d4c56572ca51)
- [Upstream third-party notices](https://github.com/lain1145141919810/HAST-SEC/blob/f4d5c9aa32f9d04e249585e0b2e6d4c56572ca51/THIRD_PARTY_NOTICES.txt)

No user avatar, upstream solver, motion data, language weights, or GPU binaries are distributed in this plugin ZIP.
