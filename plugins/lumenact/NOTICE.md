# LumenAct curve sample attribution

Performance data source LumenAct / 流明表情工坊, authored by Lumen_流明_. This package uses the upstream four original authored frame spans for clip IDs 0, 5, 23 and 77. It rebases the offsets and removes unrelated catalog entries. Frame values, widths and frame rates remain unchanged. See `sample/provenance.json` for the source and clip hashes.

The licensed performance data is distributed under CC BY 4.0. The complete license is in `sample/LICENSE-CC-BY-4.0.txt`. The original source, names and license are linked below.
