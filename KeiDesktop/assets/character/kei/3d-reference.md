## 可用于角色设计的内容

- `fbx/kei.fbx`：完整角色网格、骨骼，以及 35 个面部 BlendShape 目标；未发现动画栈。
- `pmx/kei.pmx`：55,858 个顶点、340 根骨骼、229 个刚体和 361 个关节。另有三个衣装/发色变体。四个 PMX 文件均没有 morph 表情。
- FBX 面部目标包括眨眼、微笑、眯眼、惊讶、严肃、困惑、愤怒、瞳孔大小，以及「あ・い・う・え・お」等口形。它们可以作为凯伊表情造型和口形设计的视觉参考。
- 身体骨骼覆盖头、颈、肩、臂、手、腰、腿，适合参考点头、思考、坐姿和轻微重心变化的姿态。压缩包没有可直接播放的动作片段。

## 与当前 KeiDesktop 的关系

当前 CG1 使用 `standing/Kei_Model_Physics.moc3`。这是编译后的 Cubism 模型，3D 的 BlendShape、骨骼和贴图不能直接添加为该模型的新绘制对象或参数。要增加真正的眼形、口形、手势和坐姿，需要原始 Cubism 编辑工程及对应分层原画，或单独开发 3D 渲染角色。现有的表情语义映射与轻微动作可继续使用，但不会凭此压缩包自动获得新的 Live2D 绘制内容。

建议的造型参考对应关系：

| Desktop 语义 | 3D 面部参考 |
| --- | --- |
| `neutral` | 默认脸、自然眨眼 |
| `gentle` / `small_smile` | なごみ、にこり、笑い |
| `happy` | 笑い、にこり、瞳大 |
| `serious` / `thoughtful` | 真面目、じと目、困る |
| `surprised` | びっくり、瞳大、あ |
| `flustered` / `bashful` | 困る、ウィンク系的轻微组合 |
| `sad` | 困る、下 |

口形参考应保留当前 PCM 驱动的 `OpenY` 时序；如果将来制作 Cubism 原画与参数，再以元音口形或 `MouthForm` 增加变化，不应把 3D 文件名写入 Runtime 协议。

## 素材使用边界

PMX 内嵌的作者说明署名“阿琳剑圣/银月风尘”，允许修正模型本身的物理、权重和表情问题，同时禁止二次配布、拆取部件改造其他模型及商业用途。此压缩包仅作为本机参考保存；不要复制模型或贴图进应用发布目录，也不要将其拆入现有 Live2D 模型。若将来计划直接展示或发布 3D 角色，先核对使用场景与作者许可。
