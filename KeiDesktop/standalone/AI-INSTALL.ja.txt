Windows x64 のこの PC に Kei Desktop v0.3.2 を導入してください。以下の手順を実行し、最後に起動と接続を実際に確認してください。

1. 公式リリース https://github.com/lain1145141919810/Kei-Desktop/releases/tag/v0.3.2 から Kei-Desktop-Windows-x64.zip を取得してください。GitHub Release の SHA-256 と照合し、ユーザーが書き込める新しいフォルダーに全体を展開します。以前のユーザー設定、キャラクター、記憶は保持してください。
2. 同梱の Kei Desktop.exe を起動してください。初回はユーザーが名前・人格・素材を選べるようにし、未指定なら標準設定で開始してください。日本語設定ガイドは https://github.com/lain1145141919810/Kei-Desktop/blob/v0.3.2/docs/STANDALONE.ja.md です。
3. 使用したい会話モデルの URL とモデル名を確認し、「操作 → 管理ウィンドウ → 設定 → 接続設定を開く」で設定してください。秘密鍵はユーザーがローカルで入力し、チャットやログには載せないでください。
4. 読み上げ方式をユーザーに確認してください。管理ウィンドウの「設定 → 音声読み上げ設定」から選べます。
   ・外部 TTS API を使う場合：サービスの仕様に従い、完全な POST URL、本文キー（例 input または text）、モデル名、音声 ID、必要なら Bearer キーと追加 JSON を入力します。音声バイナリを audio/* で返すサービスが対象です。この方式では GPT-SoVITS の環境や重みは不要です。
   ・GPT-SoVITS を使う場合：日本語設定ガイドに従い v3、ケイの学習済み重み、ユーザーの参照 WAV を用意し、サーバーを起動します。URL、参照音声のパス・言語・書き起こしを設定してください。
   ・読み上げを使わない場合：無効のまま進めてください。マイク入力、DSH、AstrBot も希望がある場合のみ追加してください。
5. アプリを起動し、ローカルの GET /health と日本語のテキスト会話を確認してください。読み上げを選んだ場合は短い日本語を再生し、選択した接続先から音声が返ることを確認してください。最終的にインストール先、選んだ方式、確認できた機能、追加設定が必要な項目を報告してください。
